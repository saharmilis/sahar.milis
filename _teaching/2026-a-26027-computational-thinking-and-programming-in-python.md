## Course description

An introduction to computational thinking and programming in Python, with applications in business, economics, and entrepreneurship. The course develops foundational skills in software development, programming, and data analysis, and introduces AI-assisted tools for building practical applications.

## Topics

- Computational thinking, variables, data types, conditionals, and loops.
- Python data structures, functions, libraries, and modular programming.
- Object-oriented programming, exception handling, files, and JSON.
- Data manipulation and visualisation with Pandas and Matplotlib.
- Searching, sorting, web APIs, and automation.
- Generative AI and low-code or no-code tools.
