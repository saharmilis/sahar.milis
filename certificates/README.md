# Certificates — public encrypted archives

This directory holds encrypted course certificates. Course folders are named `<academic-year><semester>-<course-number>`.

Each course has its own README, a common template and client-side viewer, plus numbered `.enc.json` files. Plaintext student details and decryption keys are **not** published here.

To view a certificate, its recipient must use their complete private URL (including the `#` fragment). Links are bearer secrets: anyone who has the complete link can decrypt that certificate.

This repository is a **demonstration only**, not an official university credential service.
